Privacy Policy — JustWaitAI

Last updated: 17 November 2026

Who uses this app

JustWaitAI is a private tool used only by the owner of the JustWait AI YouTube channel. Nobody else can sign in to it.

What data it accesses

  • YouTube Data API and YouTube Analytics API, read-only: statistics about the owner's own channel and videos, such as views, watch time, audience retention, traffic sources and viewer countries.
  • YouTube upload permission, only if granted: used to upload a video to the owner's own channel after the owner approves that video.

The app does not request access to any other Google data. It does not read comments, messages, or data about other people's accounts.

How data is used

  • Channel statistics are used only to plan and improve videos for the owner's own channel.
  • Channel statistics are not sold, not shared with third parties, and not used for advertising.
  • Channel statistics are not sent to the text, voice, or video generation services the owner uses to make videos.

Where data is stored

  • Statistics are stored in a database on the owner's own computer.
  • When the owner turns on cloud automation, statistics are processed temporarily on the owner's private GitHub Actions runners and are not saved in the code repository.
  • Access tokens are kept in a secrets folder on the owner's computer and, for automation, in GitHub's encrypted secrets for the owner's private repository. They are never published.

Related policies

Use of YouTube data is subject to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account → Third-party connections. The owner can delete the stored statistics at any time.

Contact

Questions can be sent by opening an issue in this site's repository on GitHub.
